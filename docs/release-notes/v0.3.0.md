# GitBell 0.3.0

GitBell can now update itself.

## What's new

- **Signed auto-updates.** GitBell checks for a new release shortly after it
  starts and every few hours. When one is available, a banner appears on the
  Activity view; one click downloads it, verifies its signature, installs it
  and restarts the app. Nothing is installed if the signature does not match.
- **Quieter repository.** Security-audit warnings that come from Tauri's own
  dependencies no longer open issues on the tracker.

## Upgrading

0.2.1 and earlier do not contain the updater, so this one time you need to
install 0.3.0 yourself: download the package for your system from the
assets below and install it over the existing copy. Your token (OS keyring)
and settings are kept. From 0.3.0 on, updates arrive through the banner.

| Platform | Package | Updates in-app |
|---|---|---|
| Linux | `.AppImage` | yes |
| Linux | `.deb`, `.rpm` | yes, asks for your admin password |
| Windows | `.msi`, `.exe` | yes |

Windows installers are still not code-signed, so SmartScreen may show
"Windows protected your PC": choose *More info, Run anyway*.
